# token.json — Token Metadata

This document accompanies the existing `token.json` file.

## Purpose

`token.json` contains token/collection metadata for the PharmWeb3 asset layer.

The existing file includes:

- token name and symbol;
- project description;
- utility-token attribute;
- collection/family metadata;
- IPFS-linked image asset;
- creator information.

## Engineering note

The metadata layer is intentionally kept separate from the broader healthcare application architecture.

The token is not the entire product. It is one component inside the wider PharmWeb3 product direction.

## Review

When changing `token.json`, verify:

- metadata validity;
- asset URL availability;
- creator information;
- marketplace compatibility;
- consistency with the current product documentation.
