# Engineering Labs

Runnable systems behind the PharmWeb3 technical portfolio.

## Quick start

- npm test
- npm run eval:ai
- npm run demo:ai -- "show me AI projects"
- npm run demo:arbitrage
- npm run demo:arbitrage:backtest
- npm run demo:forex
- npm run demo:forex:backtest
- npm run demo:saas
- npm run demo:telemetry

## Showcase

Open demos/showcase/index.html with a static server or deploy the demos directory to GitHub Pages.

## Standards

AI output is validated before privileged actions. Financial systems default to paper/sandbox execution. SaaS APIs require tenant context. Secrets remain environment variables.
