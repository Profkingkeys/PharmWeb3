# Gradle Wrapper Status

The Android CI pins Gradle 8.10.2 through the Gradle setup action and validates the build on every workflow run.

The repository does not hand-author the binary gradle-wrapper.jar. Official Gradle documentation states that the wrapper JAR is generated by the gradle :wrapper task and should be checked into version control. The current CI path keeps the exact Gradle version pinned while the wrapper bootstrap artifact remains a follow-up that requires a binary-safe repository write path.

Generate it with:

gradle :wrapper --gradle-version 8.10.2

Commit the generated gradle/wrapper/gradle-wrapper.jar, gradle/wrapper/gradle-wrapper.properties, gradlew and gradlew.bat together.
