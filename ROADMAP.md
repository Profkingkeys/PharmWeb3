# PharmWeb3 Roadmap

This roadmap separates product vision from what is already implemented.

## Now

### Product
- strengthen the healthcare user journey;
- improve AI-assisted triage and pharmacist handoff;
- continue improving voucher and financial-support workflows;
- document product requirements and safety boundaries.

### Engineering
- expand AI agent/tool infrastructure;
- improve telemetry;
- keep databases and secrets properly separated;
- build repeatable development environments;
- improve automated testing.

## Next

### AI
- tool registry;
- agent evaluation;
- model routing;
- retrieval/evidence workflows;
- structured action validation.

### SaaS
- partner-facing APIs;
- pharmacy workflow tools;
- admin dashboards;
- analytics and operational reporting.

### Web3
- carefully scoped reward/settlement features;
- wallet workflows;
- partner integrations;
- transparent on-chain components where they add genuine value.

## Research

Build AI-assisted biomedical evidence tooling around:

- literature retrieval;
- structured extraction;
- cross-study comparison;
- reproducible analysis;
- research collaboration.

## Long-term

Build PharmWeb3 into infrastructure that can support healthcare access at much larger scale.

That means building a system that is useful even without the Web3 layer, and using Web3 only where it improves transparency, incentives or settlement.

---

### Status language

**Implemented** means there is working code or a public product artifact.

**Prototype** means the idea has been implemented in an exploratory form.

**Research** means an engineering direction being evaluated.

**Planned** means it is part of the roadmap but not yet implemented.

This distinction is intentional.
