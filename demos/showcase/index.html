Run a lab

git clone https://github.com/Profkingkeys/PharmWeb3.git
cd PharmWeb3
npm test
npm run test:production
npm run eval:ai:production

Use Node.js 22 or later. The default evaluation uses local deterministic fixtures. Android, MySQL and optional provider integrations have their own documented prerequisites.

This portfolio contains engineering labs and educational prototypes. Passing software tests does not establish clinical validity, trading returns or production readiness.
